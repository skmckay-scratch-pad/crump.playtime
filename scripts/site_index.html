Failure-Probability Sensitivity

How sensitive are annual and multi-year failure probabilities for 31 infrastructure asset groups to their condition grades (A to F-) and to the shape of the grade-to-probability curves? The analysis is done in R and follows the global sensitivity workflow of Cushway et al. (2026). The same results are shown in several web-app frameworks so they can be compared.

Shiny · runs in browser

Shinylive app

A Shiny app compiled to WebAssembly (webR). The multi-year risk and misclassification tabs are recomputed live in the browser. The first load takes 10 to 30 seconds.

 Quarto · static + OJS

Quarto dashboard

Rendered once from R. The multi-year calculator is written in Observable JS, so it is fully interactive with no R running.

 R Markdown · static + crosstalk

flexdashboard

The older R Markdown dashboard format. Precomputed multi-year scenarios are filtered in the browser with crosstalk, and the full Sobol' table can be searched and downloaded.

 Quarto · report

Analysis report

Each step with its R code: data checks, curve shape, notch and misclassification sensitivity, multi-year risk, Sobol' indices, and facility structure comparison.
The full Shiny app (8 tabs, including the system builder) needs an R server, so it is not hosted here. Run it locally from the repository root with shiny::runApp("apps/shiny").

Iteration cap: every iteration count in the sensitivity analysis is capped at 250 (base sample and bootstrap replicates). The confidence intervals are therefore wide, and "non-influential" means "not shown to be influential at this sample size".
Data downloads: failure probabilities (CSV) · Sobol' indices (CSV)
